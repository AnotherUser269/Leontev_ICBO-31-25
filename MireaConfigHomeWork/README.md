# Транслятор учебного конфигурационного языка

## Общее описание
CLI-инструмент для трансляции текста на учебном конфигурационном языке в формат XML.

## Функции и настройки
- Поддержка комментариев (`;` и `<# #>`).
- Типы данных: числа (`[+-]?\d+\.\d+`), строки (`'...'`), списки (`list(...)`), словари (`{...}`).
- Константы: объявление `def name = value` и вычисление `$[name]`.
- Вывод синтаксических ошибок в stderr.

## Команды сборки и тестирования
- Установка зависимостей: `make install`
- Запуск тестов: `make test`
- Запуск линтера: `make lint`

## Примеры использования
```bash
cat examples/server_config.conf | ./run.sh config.xml
```
