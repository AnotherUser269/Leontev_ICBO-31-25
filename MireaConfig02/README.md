# Dependency Graph Visualizer

## 1. Общее описание
Инструмент для визуализации графа зависимостей пакетов Python (pip).
Позволяет строить графы прямых и транзитивных зависимостей, а также 
обратных зависимостей.

## 2. Описание всех функций и настроек
- `--package`: Имя анализируемого пакета (обязательно).
- `--source`: URL-адрес репозитория или путь к файлу тестового репозитория.
- `--test-mode`: Флаг для работы с тестовым репозиторием.
- `--version`: Версия пакета (по умолчанию `latest`).
- `--output`: Имя сгенерированного файла с изображением (по умолчанию `graph.png`).
- `--max-depth`: Максимальная глубина анализа (по умолчанию `-1`, без ограничений).
- `--filter`: Подстрока для фильтрации пакетов.
- `--reverse`: Вывод обратных зависимостей.
